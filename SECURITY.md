# Security Policy

## Supported versions

Security reports are accepted for the version currently published from the
`main` branch of this repository.

## Reporting a vulnerability

Please report suspected vulnerabilities privately by email to
<s.gururaghuraman@gmail.com>. Include a clear description, affected URL or
file, reproducible steps, expected and observed behavior, and any suggested
mitigation.

Do not create a public GitHub issue, publish exploit details, or share
unnecessary personal data while a report is being assessed.

## Response process

Reports will be acknowledged when possible, assessed for impact, and addressed
in a reasonable timeframe. Disclosure timing will be coordinated with the
reporter after a fix or mitigation is available.

## Scope

This policy covers source files and content served by this GitHub Pages
portfolio. It does not authorize testing that degrades availability, accesses
data that does not belong to you, or targets unrelated third-party services.
